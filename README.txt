كاشف — نسخة تجريبية 0.1

المحتويات:
- index.html: الواجهة العربية
- styles.css: التصميم المتجاوب
- app.js: سجل النطاقات، الفحص الأولي، وإعداد البلاغات
- manifest.webmanifest و sw.js: دعم التثبيت والعمل الأساسي دون اتصال
- icon.svg: أيقونة التطبيق

طريقة التجربة على أندرويد:
1) ارفع الملفات إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو استضافة ويب تملكها).
2) افتح رابط index.html عبر Chrome.
3) من قائمة Chrome اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق" إن ظهر الخيار.
4) سجّل نطاقا مصرحا به في قسم "نطاق الإذن" قبل تجربة الفحص.

مهم:
- Service Worker وPWA يحتاجان عادة إلى HTTPS أو localhost.
- لا تفتح الملف محليا وتتوقع أن تعمل كل خصائص PWA.
- التخزين محلي في المتصفح فقط؛ مسح بيانات المتصفح قد يحذف السجل.
- فحص الويب يرسل طلب GET واحدا، بلا بيانات اعتماد، ويطابق اسم المضيف تطابقا تاما.
- المتصفح قد يمنع قراءة الاستجابة بسبب CORS؛ لا يحاول التطبيق تجاوز ذلك.
- نتائج الترويسات مؤشرات وليست إثباتا لثغرة قابلة للمكافأة.
- لا يوجد في هذا الإصدار تحليل APK آلي، ولا اختبار اختراق أو استغلال آلي.
- راجع إذن المالك ونطاق البرنامج والقوانين المحلية قبل أي اختبار.
